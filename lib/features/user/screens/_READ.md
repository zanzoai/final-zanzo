 User Screens — README

This folder contains the primary user-side screens used in the task lifecycle and job tracking experience inside the Zanzo AI app.
Each file is cleaned, structured, and fully documented for easy navigation.

⸻

📄 1. job_history_screen.dart

Purpose

Displays the list of previously completed jobs for the logged-in user.

Key Features
	•	Loads job history using the backend /jobs/history endpoint.
	•	Shows job title, date/time, location, and status.
	•	Tapping an item opens the Track Job or Review Task screen depending on job state.
	•	Gracefully handles empty or error states.

⸻

📄 2. profile_screen.dart

Purpose

Shows the logged-in user’s profile details and quick actions.

Key Features
	•	Fetches current user details (name, email, profile photo).
	•	Shows shortcuts (Edit Profile, Payment Methods, Help & Support, Logout).
	•	Uses SharedPreferences to read user session and perform logout.
	•	Clean and UI-focused; no heavy logic.

⸻

📄 3. review_task_screen.dart

Purpose

Allows the user to review/edit the polished task generated by Zenzo AI before posting.

Key Features
	•	Shows polished task title, description, suggested time, materials, etc.
	•	Lets user edit fields before submitting the final job.
	•	Handles special cases like voice-tasks, quick-tasks, advanced polishing.
	•	Submit button → calls /process_task or /jobs API depending on flow.
	•	Big file with multiple UI sections but no backend logic changed.

⸻

📄 4. track_job_screen.dart

Purpose

Shows real-time tracking of an active job from “searching crew” → “completed”.

Key Features
	•	Realtime updates using Supabase stream.
	•	Polling fallback if realtime drops.
	•	Shows assigned ZenCrew partner details and allows chat.
	•	Displays Start PIN, End PIN, time-worked, and friendly progress.
	•	Animated vertical timeline with 6 stages:
	1.	Finding nearest crew
	2.	Agent accepted
	3.	Travelling 🚗
	4.	Arrived 📍
	5.	Work in progress 🛠️
	6.	Job accomplished 🏁
	•	Safely cleans timers and subscriptions on dispose.
